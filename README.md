## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Profile Store** | Save unlimited named control profiles for any input device |
| **Quick Switch** | Apply any saved profile with a single click before launching |
| **Conflict Check** | Highlights duplicate button assignments within a profile |
| **Import/Export** | Share control profiles as files with other players |
